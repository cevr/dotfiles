# Bible Study — Structural & Literary Analysis

The Bible's own internal structure is the primary interpretive key. Structure reveals theology.
**The structure IS the message.**

## Core Method

Biblical authors deliberately arranged text into literary patterns (chiasms, parallels,
inclusios) that encode theological meaning. Discover structure → extract theology → state
the point → show the proof.

**Always lead with meaning, not method.** The human question first, then the structural evidence.

## Workflow

### 1. Read the Full Passage
Read in KJV (default) or requested translation. Note repeated words, phrases, thematic shifts,
and apparent section breaks.

### 2. Identify Literary Structure
Apply in order — see [references/structures.md](references/structures.md) for patterns and examples:

1. **Chiastic patterns** — A-B-C-B'-A' mirroring. The center = theological climax.
2. **Parallel tables** — Side-by-side correspondences between passages
3. **Inclusio/bookends** — Opening/closing elements bracketing a passage
4. **Ring composition** — Multiple nested layers of bracketing
5. **Chronological reordering** — Text out of time-order for structural reasons

### 3. Perform Word Studies
See [references/word-studies.md](references/word-studies.md):

- Count occurrences (symbolic counts, e.g. "ten" 10x in Daniel 1)
- Trace Hebrew/Greek roots with Strong's numbers (#NNNN)
- Track vocabulary clusters — words appearing ONLY in paired sections confirm structure
- Check name meanings and alphabetical ordering

### 4. Map Cross-References
See [references/cross-references.md](references/cross-references.md):

- OT → NT typological fulfillment
- Inter-book parallels (recapitulation — same prophecy retold differently)
- Sanctuary mapping (events → tabernacle furniture/rituals)
- Prophetic timeline (day-year principle)

### 5. Decode Symbolism
See [references/symbolism.md](references/symbolism.md):

- Numbers, animals, metals, colors, directions, body parts, garments, names
- **Scripture interprets Scripture.** Every symbol must have a biblical definition. If undefined, flag as uncertain.

### 6. State the Theological Point
Answer: **"So what?"** — What does this reveal about God? What does it demand? How does it connect?

## Conventions

- KJV default; Strong's numbers as #NNNN
- Chiasm labels: A, B, C... with primes A', B', C' for mirrors
- Nested: Latin → Roman → lowercase → Greek/Hebrew letters
- Mark uncertainty explicitly
- Distinguish what text *says* from what it *implies*
- **King = Kingdom** in Hebrew prophetic thought (Daniel 2:37-39; 7:17,23)
- **Beast = King = Kingdom** — interchangeable in Daniel/Revelation
